# Mantenimiento del proyecto

Leer CITYNIZER_MADRID.md antes de trabajar. Registrar acuerdos y cambios con fecha y fuente. Diferenciar el alcance vigente de propuestas y antecedentes; Madrid de Sevilla; y tareas pendientes de trabajo ejecutado.

Usar el manual CTZ_Branding.pdf como referencia visual: negro y blanco, Suisse y Coign, y sistema de río, horizonte y pegatinas. Conservar diseños y firmas cuando se soliciten cambios puntuales.

Mantener los enlaces del README y el documento maestro. No guardar credenciales, contraseñas o tokens. Comprobar el commit remoto antes de afirmar que la documentación está sincronizada. Conservar el carácter interno de contratos, datos fiscales y condiciones comerciales.
